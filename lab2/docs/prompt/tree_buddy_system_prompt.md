必须完成的事情：
- 新增一个独立的线段树/显式树版 Buddy System，并接入现有 `pmm_manager`。
- 支持物理页初始化、连续页分配、释放、空闲页统计和基本检查。
- 非 2 的幂请求要分配能够容纳它的最小 2 的幂 block。

实现方法：

- 分配时在树上寻找能够满足请求的最小块，必要时向下分裂。
- 释放时恢复对应节点，并在两个子块都空闲时向上合并。
