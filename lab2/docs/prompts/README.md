# Lab2 提示词

提示词按 Lab0.5 的 [PROMPT]、[RELY]、[GUARANTEE]、[SPECIFICATION] 四段组织。课程没有规定具体文件名，当前名称按功能命名。

- page_init_prompt.md：宋昕睿的内存初始化提示词整理版，补全原稿中的接口说明和实际约束。
- best_fit_prompt.md：张博翔的首次从骨架实现提示词，按原约定整理。
- buddy_system_prompt.md：詹力臻的 Buddy 实现提示词。
- buddy_system_test_prompt.md：Buddy 独立测试提示词，补充前后置条件与测试有效性说明。
- slub_prompt.md：詹力臻的 SLUB 实现提示词，将原稿的接口占位替换为实际签名。
- slub_test_prompt.md：本次按现有测试代码整理补充的独立测试规格，不是过去对话的逐字记录。

原始提示词仍保留在父目录。报告附录收录以上六份完整文本，不把缺失的历史轮次补写成事实。
